Päivä 1 · Luennon koodiesimerkit

Pidä oma muistikirjasi auki Positronissa. Demokoodi etenee luennon järjestyksessä. Harjoittele omassa tiedostossasi ja avaa mallikoodi vasta oman kokeilun jälkeen.

Konsoli ja Quarto

Laske sokki-indeksi konsolissa. Tallenna seuraavaksi arvot nimillä ja käytä niitä laskussa.

110 / 85
#> [1] 1.294118
syke <- 110
systolinen <- 85
syke / systolinen
#> [1] 1.294118
sykkeet <- c(72, 88, 110, 95)
mean(sykkeet)
#> [1] 91.25

Avaa ohje Positronin Help-paneeliin.

?mean

Kokeile itse · Koodisolu ja Preview

Tallenna sykearvo 110 ja systolinen paine 85 koodisoluun. Laske sokki-indeksi, kirjoita tuloksesta muistiinpano solun alle ja avaa Preview.

HuomautusMallikoodi 
syke <- 110
systolinen <- 85
syke / systolinen

Paketit ja aineisto

Aja oman muistikirjasi valmistelusolu ennen esimerkkejä. Se lataa tidyverse-paketit ja luo muuttujan news NHSRdatasets-paketin synteettisestä aineistosta.

# Synteettisen opetusaineiston valmistelu. Muokkaukset opetetaan päivänä 2.
library(tidyverse)

news <- NHSRdatasets::synthetic_news_data |>
  mutate(
    sex = factor(male, levels = 0:1,
                 labels = c("Female", "Male")),
    oxygen = factor(sup, levels = 0:1,
                    labels = c("Room air", "Oxygen")),
    avpu = factor(alert, levels = 0:3,
                  labels = c("A", "V", "P", "U")),
    outcome = factor(died, levels = 0:1,
                     labels = c("Survived", "Died")),
    risk = cut(NEWS, breaks = c(-Inf, 4, 6, Inf),
               labels = c("Low (0-4)", "Medium (5-6)",
                          "High (7+)"))
  ) |>
  select(age, sex, NEWS, risk, resp, sat, oxygen,
         syst, dias, pulse, temp, avpu, died, outcome)

Ensimmäinen hajontakuva

Aineisto. Kerro ggplot2:lle, mistä aineistosta kuva piirretään.

ggplot(data = news)

Akselit. Liitä ikä x-akselille ja systolinen verenpaine y-akselille.

ggplot(data = news, aes(x = age, y = syst))

Pisteet. Lisää geom_point(). Lyhyemmässä muodossa argumenttien nimet voi jättää pois.

ggplot(data = news, aes(x = age, y = syst)) +
  geom_point()
ggplot(news, aes(age, syst)) +
  geom_point()

Väri, läpinäkyvyys ja suora

Väritä pisteet muuttujan mukaan tai anna kaikille sama väri. Säädä läpinäkyvyyttä ja vertaa tasoitettua käyrää suoraan.

ggplot(news, aes(age, syst, colour = sex)) +
  geom_point()
ggplot(news, aes(age, syst, colour = NEWS)) +
  geom_point()
ggplot(news, aes(age, syst)) +
  geom_point(colour = "steelblue")
ggplot(
  news,
  aes(age, syst, colour = "steelblue")
) +
  geom_point()
ggplot(news, aes(age, syst)) +
  geom_point(
    colour = "steelblue",
    alpha = 0.3
  )
ggplot(news, aes(age, syst)) +
  geom_point() +
  geom_smooth()
ggplot(news, aes(age, syst)) +
  geom_point() +
  geom_smooth(method = "lm")

Lukumäärät ja osuudet

geom_bar() laskee ryhmien lukumäärät. Valinnalla position = "fill" kunkin pylvään kokonaiskorkeus on yksi.

ggplot(news, aes(oxygen)) +
  geom_bar()
ggplot(news, aes(oxygen, colour = outcome)) +
  geom_bar()
ggplot(news, aes(oxygen, fill = outcome)) +
  geom_bar()
ggplot(news, aes(oxygen, fill = outcome)) +
  geom_bar(position = "fill")
ggplot(news, aes(risk, fill = outcome)) +
  geom_bar(position = "fill")

Rinnakkaiset pylväät ovat lisäesimerkki.

ggplot(news, aes(risk, fill = outcome)) +
  geom_bar(position = "dodge")
